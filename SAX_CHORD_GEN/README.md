# Real-Time Microphone Chord Detector with Alto Saxophone Transposition
### אפליקציית זיהוי אקורדים בזמן אמת מהמיקרופון עם טרנספוזיציה לסקסופון אלט

אפליקציית דסקטופ מבוססת **Python**, **Librosa** ו-**PySide6** לזיהוי אקורדים בזמן אמת משיר או כלי נגינה המנגן דרך המיקרופון. האפליקציה מציגה מול המשתמש:
1. **אקורד מקור (Concert Pitch)** – כפי שמנוגן בגיטרה/פסנתר/שיר.
2. **אקורד מותאם לסקסופון אלט (Alto Sax Eb Transposition)** – הטרנספוזיציה המדויקת לנגינה בסקסופון אלט (+9 סמיטונים).
3. **ויזואליזציה של התפלגות התדרים (Chromagram)** – 12 דרגות הסולם המוזיקלי בזמן אמת.
4. **היסטוריית אקורדים שנזעקו** עם אפשרות ניקוי וייצוא לקובץ CSV.

## 🎼 כללי הטרנספוזיציה לסקסופון אלט ($E\flat$)

סקסופון אלט הוא כלי בטרנספוזיציית **$E\flat$**. פירוש הדבר שכאשר הנגן מנגן את התו **C** (דו) בתווים של סקסופון אלט, הצליל הנשמע בפועל (Concert Pitch) הוא **$E\flat$**.

לכן, כדי לנגן צליל קונצרטי **X**, נגן סקסופון אלט צרך לקרוא ולנגן **$X + 9$ סמיטונים** (או $-3$ סמיטונים):

| אקורד קונצרט (Concert Pitch) | אקורד לסקסופון אלט (Alto Sax Eb) |
|---|---|
| **C** | **A** |
| **C# / Db** | **A# / Bb** |
| **D** | **B** |
| **D# / Eb** | **C** |
| **E** | **C#** |
| **F** | **D** |
| **F# / Gb** | **D# / Eb** |
| **G** | **E** |
| **G# / Ab** | **F** |
| **A** | **F#** |
| **A# / Bb** | **G** |
| **B** | **G#** |
